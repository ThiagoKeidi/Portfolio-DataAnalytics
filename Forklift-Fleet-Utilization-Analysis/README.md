# 🚜 Forklift Fleet Utilization Analysis

## Overview

This project was developed to monitor forklift fleet utilization and identify opportunities to optimize asset allocation and reduce unnecessary operational costs.

The solution measures the effective use of forklifts by comparing actual operating hours, collected through hour meter readings, with the expected operating hours contracted for each period.

By identifying underutilized fleets, management can make informed decisions regarding fleet sizing, utilization improvement, and operational efficiency.

---

## Business Challenge

Forklift fleets represent a significant operational investment.

Without proper monitoring, it becomes difficult to determine whether the contracted fleet size matches the actual operational demand.

The challenge was to create a tool capable of measuring utilization rates and highlighting assets that were not being used to their full potential.

---

## Solution

A Power BI dashboard was developed to compare:

- Initial hour meter readings
- Final hour meter readings
- Actual operating hours
- Expected operating hours
- Fleet utilization percentage

The solution allows managers and supervisors to analyze utilization performance across different fleets, models, and responsible managers.

---

## Monthly Analysis

The monthly analysis page allows users to compare operating hours against expected hours during specific periods.

### Key Features

- Monthly utilization monitoring
- Fleet filtering
- Model filtering
- Manager filtering
- Operating hours analysis
- Utilization percentage calculation

---

## Year-over-Year Comparison

The annual analysis page compares utilization performance between two selected years.

This enables users to evaluate long-term trends and determine whether fleet usage is improving or declining over time.

### Key Features

- Annual utilization comparison
- Year-over-year performance analysis
- Utilization growth tracking
- Operating hour comparison
- Expected hour comparison

---

## Key Metrics

### Utilization Percentage

Measures the ratio between actual operating hours and expected operating hours.

### Actual Operating Hours

Calculated through the difference between initial and final hour meter readings.

### Expected Operating Hours

Represents the total operating hours contracted or planned for the selected period.

### Utilization Difference

Measures performance variation between selected periods or years.

---

## Business Value

The solution helps identify underutilized assets and supports fleet optimization decisions by comparing actual equipment usage against contracted operating capacity.

This approach contributes to cost reduction, improved asset allocation, and more efficient operational planning.
